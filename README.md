# 庭审旁听准备页

面向法律社团学生的纯前端小工具：录入法院公告 / 补充通知 / 更正公告 / 访客须知，结合个人准备情况，自动核对旁听条件并生成可勾选、可打印的材料卡。**全部数据只存本机浏览器 IndexedDB，不上传。**

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建（tsc + vite）
npm run preview  # 预览构建产物
```

## 功能

- **公告管理**：录入发布日期、案号、院区、法庭、允许对象、证件原件/复印件、入场截止、安检入口、步行时间，并关联原文片段。
- **更正解析**：更正公告仅在「明确指向被更正公告 + 明确指向条款 + 案号/院区范围相交 + 发布日期不早于底稿」时覆盖旧条款；指向不明、缺发布日期或多则更正冲突时，**保留待核实**，不改动任何条款。
- **我的准备**：年龄、同行关系、拟旁听场次、到达时刻、已有纸件份数。
- **核对结论**：身份条件、纸件份数、场次重叠、跨院区步行、入场截止五项核对；每条结论带时间带与可回看的公告依据；SVG 时间带图以红框定位**最早问题**。
- **材料卡**：按场次与装袋顺序生成，可勾选；每项结论/材料卡记录来源内容哈希，**资料变化只作废受影响的结果**，其余勾选保留。
- **打印**：一键打印线下核对卡（打印样式仅输出核对卡）。

## 技术

React 18 + TypeScript + Vite + 原生 SVG + 原生 IndexedDB（无运行时第三方依赖）。
